# Controle de Estoque

Sistema simples para pequenos comércios cadastrarem produtos e controlarem a quantidade em estoque.
Feito com HTML, CSS, JavaScript e LocalStorage (sem servidor e sem banco de dados).

## Funcionalidades
- RF01 Login
- RF02 Cadastrar produtos
- RF03 Listar produtos
- RF04 Editar produtos
- RF05 Excluir produtos
- RF06 Registrar entrada
- RF07 Registrar saída
- RF08 Alerta de estoque baixo

## Acesso de demonstração
Usuário: `admin` — Senha: `1234`

## Observações
- Os dados ficam salvos no navegador (LocalStorage) de quem usa o sistema.
- O login é apenas demonstrativo: a senha fica visível no código e não protege dados reais.
